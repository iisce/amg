## Pause Policy

### Who Can Pause?

Only select shared desk subscription plans can be paused:

| Plan               | Can Pause? | Maximum Days |
| ------------------ | ---------- | ------------ |
| Hybrid Flexi       | ✅ Yes     | 3 days       |
| Half Flexi Monthly | ✅ Yes     | 5 days       |
| Monthly Plan       | ✅ Yes     | 10 days      |
| All other plans    | ❌ No      | -            |

### Pause Rules

1. **Private offices cannot be paused** - Office rental continues regardless
2. **Daily/Weekly plans cannot be paused** - Too short duration
3. **Pause extends end date** - Subscription end date is extended by pause duration
4. **One active pause at a time** - Cannot stack multiple pauses
5. **Pause history tracked** - All pauses are recorded for transparency

### How to Pause

1. Go to Dashboard → Subscriptions
2. Select your active subscription
3. Click "Pause Subscription"
4. Choose pause duration (up to your plan maximum)
5. Subscription will automatically resume after pause period

## Technical Reference

### Database Schema

Prices are stored in **kobo** (smallest currency unit):

```
₦5,500 = 550,000 kobo
₦1 = 100 kobo
```

### Pricing Plan Fields

| Field             | Type    | Description                                |
| ----------------- | ------- | ------------------------------------------ |
| `price`           | Int     | Price in kobo                              |
| `unit`            | String  | day, week, month, hour                     |
| `daysAllowed`     | Int?    | Days allowed per period (null = unlimited) |
| `maxPauseDays`    | Int     | Maximum days subscription can be paused    |
| `carryOver`       | Boolean | Whether unused days carry over             |
| `timeRestriction` | String? | Time window (e.g., "18:00-21:00")          |
| `dayRestriction`  | String? | Day restriction (e.g., "SATURDAY")         |

### Membership Fields

| Field             | Type      | Description                         |
| ----------------- | --------- | ----------------------------------- |
| `daysAllowed`     | Int?      | Days allowed for this subscription  |
| `pausedAt`        | DateTime? | When subscription was paused        |
| `totalPausedDays` | Int       | Total days paused in current period |
| `pauseHistory`    | Json?     | Array of pause/resume records       |

### VAT Calculation

VAT is calculated at checkout:

```
Subtotal: Plan price
VAT: Subtotal × 7.5%
Total: Subtotal + VAT
```

Example:

```
Monthly Plan: ₦46,500
VAT (7.5%): ₦3,487.50
Total: ₦49,987.50
```
